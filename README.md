# Text Formatter

A simple **Text Editor / Text Formatter** built using **HTML, CSS, and JavaScript**.

This project allows users to enter text and apply different formatting options such as uppercase, lowercase, capitalize, bold, italic, and underline.

## Features

* Convert text to **UPPERCASE**
* Convert text to **lowercase**
* **Capitalize** text
* Make text **Bold**
* Make text *Italic*
* Add <u>Underline</u>
* Displays the output while typing
* Simple and clean user interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Type your text in the input field.
5. Click the formatting buttons to modify the output.

## Formatting Options

| Button | Function   |
| ------ | ---------- |
| ABC    | Uppercase  |
| abc    | Lowercase  |
| Abc    | Capitalize |
| B      | Bold       |
| /      | Italic     |
| ABC    | Underline  |
